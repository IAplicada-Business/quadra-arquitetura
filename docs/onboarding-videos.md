# Vídeos do onboarding: passo a passo

Guia para subir um vídeo e vinculá-lo ao onboarding do cliente (a "Tela 0" da Trilha do Cliente).

O caminho principal é o **YouTube como vídeo não listado**: o vídeo não aparece em buscas nem no canal, só quem tem o link assiste. O **Google Drive** funciona como alternativa.

## 1. Subir no YouTube como não listado (recomendado)

1. Entre em [studio.youtube.com](https://studio.youtube.com) com a conta da Quadra.
2. Clique em **Criar** (canto superior direito) → **Enviar vídeos** e escolha o arquivo.
3. Preencha o título. Na pergunta sobre conteúdo para crianças, marque **Não, não é conteúdo para crianças**.
4. Avance até a etapa **Visibilidade** e marque **Não listado**.
5. Clique em **Salvar** e espere o processamento terminar.
6. Copie o link do vídeo, por um destes caminhos:
   - na tela final do envio, clique no ícone de copiar ao lado do **Link do vídeo**; ou
   - abra o vídeo no YouTube e clique em **Compartilhar** → **Copiar**.

O link fica parecido com `https://youtu.be/dQw4w9WgXcQ`.

> Não use o link do YouTube Studio (`studio.youtube.com/...`) nem o de uma playlist. O sistema avisa se colar um desses.

## 2. Alternativa: Google Drive

1. Envie o vídeo para uma pasta do Drive da Quadra e espere o processamento (o Drive mostra "processando" por alguns minutos em vídeos grandes).
2. Clique com o botão direito no vídeo → **Compartilhar**.
3. Em **Acesso geral**, troque "Restrito" por **Qualquer pessoa com o link** (como Leitor).
4. Clique em **Copiar link** → **Concluído**.

O link fica parecido com `https://drive.google.com/file/d/1AbC.../view?usp=sharing`.

> Se o acesso continuar como "Restrito", o cliente vê uma tela pedindo login no Google em vez do vídeo.
> Use o link do **arquivo**, não o da pasta.

## 3. Vincular o vídeo no sistema

**Para todas as obras (modelo):**
1. Vá em **Configurações → Onboarding**.
2. Escolha o modelo (ex.: Residencial) e clique em editar na seção desejada, por exemplo a primeira, que é a capa.
3. Cole o link no campo **Vídeo (YouTube não listado ou Google Drive)**.
4. Confira:
   - abaixo do campo aparece "YouTube reconhecido" ou "Google Drive reconhecido";
   - a prévia ao lado mostra o player.
5. Clique em **Salvar modelo**.

**Só para uma obra:**
1. Abra a obra → aba **Onboarding**.
2. Edite a seção e cole o link do mesmo jeito.
3. Clique em **Salvar para esta obra**. Isso cria uma cópia só daquela obra; o modelo não muda.

O link do campo dá acesso a um passo a passo resumido em **Como colocar o vídeo**.

## 4. Se aparecer um erro no campo

| Mensagem | O que fazer |
|---|---|
| Isso não é um link | Cole o endereço completo, começando com `https://`. |
| Link do YouTube incompleto | Copie de novo pelo botão Compartilhar; o link foi cortado. |
| Esse é o link de uma playlist | Abra o vídeo e copie o link dele. |
| Esse é o link do YouTube Studio | No Studio, em Detalhes, copie o "Link do vídeo". |
| Esse é o link de uma pasta do Drive | Abra o vídeo e use Compartilhar → Copiar link. |
| Link do Google Drive incompleto | Copie de novo pelo botão Copiar link. |
| Link não reconhecido | Use um link do YouTube ou do Google Drive. |

Enquanto houver erro, o botão de salvar fica desabilitado e um aviso no topo indica a seção.

## 5. Conferir como o cliente vê

1. Na obra, aba **Onboarding**, clique em **Abrir portal**.
2. Na primeira visita, a Tela 0 mostra o vídeo da capa.
3. Para ver de novo depois de entrar, use **Boas-vindas** no menu do portal.
